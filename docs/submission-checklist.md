# GitHub Submission Checklist

Use this checklist before submitting the GitHub repository URL in Google Classroom.

## Repository

- [ ] Repository has a clear project name.
- [ ] Repository is public or accessible to the lecturer/evaluator.
- [ ] Final project source code is pushed.
- [ ] Repository URL works correctly.

## README

- [ ] Project title is included.
- [ ] Project description is included.
- [ ] Problem statement is included.
- [ ] Project objectives are included.
- [ ] Main features are included.
- [ ] Technologies/tools used are included.
- [ ] Project scope is included.
- [ ] Student name and student details are completed.

## Documentation

- [ ] Project proposal is included.
- [ ] Requirements baseline is included.
- [ ] Requirements documentation is included.
- [ ] Project planning document is included.
- [ ] Other relevant documentation is included if required by the lecturer.

## Repository Cleanliness

- [ ] Files and folders are organized.
- [ ] Meaningful file and folder names are used.
- [ ] Runtime session files are not uploaded.
- [ ] Unnecessary upload files are not uploaded.
- [ ] Only project-related files are included.
- [ ] Commit messages are meaningful.

## Final Submission

Submit this format:

`https://github.com/nusky437/notice_board_system`
